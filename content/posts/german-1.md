### Teil 2: 元音 a e u i o 和辅音 p b t d k g m n s ß f w v

#### 元音（Vokale）

| 字母 | 音标 | 例词 | 说明 |
|------|------|------|------|
| **a, aa, ah** | [a:] | da, Waage, Bahn | **长音 a** |
| **a** | [a] | dann, Mann, Mappe | **短音 a** |
| **e, ee, eh** | [e:] | Café, Tee, gehen | **长音 e** |
| **e** | [ɛ] | denn, Hemd, nett | **短音 e** |
| **e** | [ə] | Name, Ehe, Tage | **弱化音 e**（非重读音节） |
| **u, uh** | [u:] | du, gut, Huhn | **长音 u** |
| **u** | [u] | dumm, Hund, Mund | **短音 u** |
| **i, ie, ih, ieh** | [i:] | Kino, die, ihm, sieht | **长音 i** |
| **i** | [i] | bitte, Mitte, Wind | **短音 i** |
| **o, oo, oh** | [o:] | Ofen, Boot, ohne | **长音 o** |
| **o** | [ɔ] | Bonn, oft, kommt | **短音 o** |

#### 读音规则：元音长短音

**长音规则：**
1. 元音字母**重叠**时：Waage, Tee, Boot
2. 元音字母 **ie** 发长音 [i:]：die, Sie, wie
3. 元音字母后有 **h**（h 不发音）时：ihn, nah, ohne
4. 以元音**结尾**的音节，或元音**自成音节**时：Adam, haben, oben
5. 元音后只有**一个**辅音字母时：gut, Hof, Tag

**短音规则：**
1. 元音后有两个或以上辅音字母：kommen, ist
   - 例外（长音）：hoch, Mädchen, Obst, Ostern
2. 有些单音节词中单个辅音前也发短音：das, ob, mit

#### 辅音（Konsonanten）

| 字母 | 音标 | 例词 | 说明 |
|------|------|------|------|
| **p, pp** | [p] | Papa, Mappe | 清辅音 |
| **b**（词尾/辅音前） | [p] | ab, gab, Obst | **b → 清化 [p]** |
| **b, bb** | [b] | Bahn, Bitte | 浊辅音 |
| **t, tt, th, dt** | [t] | gut, Bett, Thema | 清辅音 |
| **d**（词尾/辅音前） | [t] | Bad, Kind | **d → 清化 [t]** |
| **d, dd** | [d] | da, Ende, Pudding | 浊辅音 |
| **k, ck** | [k] | kann, dick | 清辅音 |
| **g**（词尾/辅音前） | [k] | Tag, mag, sagt | **g → 清化 [k]** |
| **g** | [g] | gut, Gas, geben | 浊辅音 |
| **m, mm** | [m] | Mann, kommen | 鼻音 |
| **n, nn** | [n] | nah, denn | 鼻音 |
| **s**（词尾/辅音前） | [s] | das, bis, Bus | **清辅音 [s]** |
| **ss, ß** | [s] | essen, Fuß | 清辅音 |
| **s**（元音前） | [z] | See, sieben, Sonne | **浊辅音 [z]** |
| **f, ff, ph** | [f] | Hof, offen, Physik | 清辅音 |
| **v**（德语词） | [f] | von, Vieh, Vater | **清辅音 [f]** |
| **v**（外来词元音前） | [v] | Vase, Visa, Visum | **浊辅音 [v]** |
| **w** | [v] | wann, wissen, wie | 浊辅音 |

#### 重点辅音规则

> **⚠️ 关键规则：浊辅音清化（Auslautverhärtung）**
>
> **b, d, g** 在词尾或辅音前清化为 **[p], [t], [k]**
> - Dieb → [di:p]、Bad → [ba:t]、Tag → [ta:k]
> - 但加元音后恢复：Tage → [ta:gə]

> **⚠️ s 的发音：**
> - 元音前 = **[z]**（浊）：sie, lesen
> - 其他情况 = **[s]**（清）：bist, das
> - ss / ß = **[s]**（清）：essen, Fuß

> **⚠️ v 的发音：**
> - 德语词中 = **[f]**：von, Vieh
> - 外来词中元音前 = **[v]**：Vase, Visa

| 字母 | 音标 | 例词 | 说明 |
|------|------|------|------|

| **-er**（词尾） | [ɐ] | Mutter, Vater, Wasser | 弱化 [ɐ] |

#### 辅音 z, ts, ds, tz, t(ion), x, chs, (c)ks, ch

| 字母 | 音标 | 例词 |
|------|------|------|
| **z** | [ts] | zehn, Zeit, ganz |
| **ts** | [ts] | bereits, nichts, Rätsel |

| **tz** | [ts] | Katze, Platz, sitzen |
| **t(ion)** | [tsi̯o:n] | Aktion, Nation |
| **x** | [ks] | Examen, Taxi, Fax |
| **chs** | [ks] | sechs, wächst, Fuchs |
| **(c)ks** | [ks] | Knicks, tricksen |

#### ch 的两种发音

| 发音 | 出现位置 | 例词 |
|------|----------|------|
| **[ç]**（Ich-Laut） | 元音 e, i, ä, ö, ü, ei, eu 和辅音后 | China, dich, Licht, reich |
| **[x]**（Ach-Laut） | 元音 **a, o, u, au** 后 | Buch, noch, lachen, Bauch |

> **-ig 词尾规则：** -ig 在词尾读 **[ɪç]**（wichtig, richtig），-ig 后加 e 时读 **[ɪgə]**（richtige）

#### 读音规则总结

1. **r 的发音：**
   - 元音前 / 短元音后 = 颤音 [r]：Rad, recht
   - 长元音后 = [ɐ]：Uhr, vier
   - 词尾 -er / 前缀 ver-, er-, zer- = [ɐ]：Vater, verstehen

2. **ch 发音：**
   - a, o, u, au 后 = [x]：lachen, noch, suchen, Bauch
   - 其他元音后 = [ç]：feucht, Licht, leicht

### Teil 4: 辅音组合 + 词重音 + 语调

#### 辅音组合（Konsonantenverbindungen）

| 字母 | 音标 | 例词 | 说明 |
|------|------|------|------|
| **sch** | [ʃ] | Schule, Tisch, schnell | 类似英语 sh |
| **ch**（外来词） | [ʃ] | Champagner, Chef | 少数法语借词 |
| **tsch** | [tʃ] | Deutsch, Matsch | 类似英语 ch |
| **st**（词首） | [ʃt] | Stadt, Student, Stuhl | t 不送气 |
| **st**（词中/尾） | [st] | Fenster, Kunst, Lust | |
| **sp**（词首） | [ʃp] | Sport, spät, Sprache | p 不送气 |
| **sp**（词中/尾） | [sp] | Wespe, Aspekt, Respekt | |
| **pf** | [pf] | Apfel, Pferd, Kopf | 德语特有 |
| **qu** | [kv] | Quelle, Qualität, Quiz | |
| **ng** | [ŋ] | Zeitung, Anfang, jung | 类似英语 ng |
| **nk** | [ŋk] | Bank, Dank, Geschenk | |

#### 读音规则

1. **st-/sp- 在词首发 [ʃt]/[ʃp]**，此时 t/p 不送气（不爆破）
   - 例：stehen [ʃte:ən], spät [ʃpɛ:t]
   - 非词首位置读 [st]/[sp]：Nest, Wespe

2. **ng 发 [ŋ]**（单一鼻音，不要加 g 音）
   - 例：lang, jung
   - ng + e → [ŋə]：lange [laŋə], Enge [ɛŋə]

---

#### 词重音（Wortakzent）

德语词重音规则：

| 规则 | 例词 |
|------|------|
| 1. 德语单词重音一般在**第一个音节** | **Ma**ppe, **ha**ben, **sa**gen |
| 2. 复合词重音在第一个词上 | **Tisch**tennis, **Super**markt |
| 3. 带非重读前缀 be-, ge-, er-, ver-, zer-, ent-, emp- 的词，重音在**第二个音节** | be**su**chen, ge**fal**len, er**klä**ren, ver**ste**hen |
| 4. 许多外来词重音在**最后一个或倒数第二个音节** | Mu**sik**, Stu**dent**, Universi**tät** |
| 5. 缩写词重音在**最后一个字母** | BR**D**, US**A**, E**U** |

## Einheit 2 — 相识（Kennenlernen）

### 语法 I：冠词与名词的第一格（Artikel und Substantiv im Nominativ）

德语名词有**三个性**：阳性（m.）、阴性（f.）、中性（n.）

#### 定冠词（bestimmter Artikel）

| 性 | Nominativ | 例 |
|----|-----------|-----|
| 阳性 m. | **der** | der Mann, der Tisch |
| 阴性 f. | **die** | die Frau, die Lampe |
| 中性 n. | **das** | das Kind, das Buch |
| 复数 Pl. | **die** | die Kinder, die Bücher |

#### 不定冠词（unbestimmter Artikel）

| 性 | Nominativ | 例 |
|----|-----------|-----|
| 阳性 m. | **ein** | ein Mann |
| 阴性 f. | **eine** | eine Frau |
| 中性 n. | **ein** | ein Kind |
| 复数 Pl. | —（无） | Kinder, Bücher |

> **重要：** 德语名词首字母**永远大写**！每个名词都要记住它的**性**（der/die/das）！

---

### 语法 II：人称代词第一格（Personalpronomen im Nominativ）

| 人称 | 单数 | 复数 |
|------|------|------|
| 第一人称 | **ich**（我） | **wir**（我们） |
| 第二人称（亲密） | **du**（你） | **ihr**（你们） |
| 第二人称（尊称） | **Sie**（您） | **Sie**（您们） |
| 第三人称阳 | **er**（他） | **sie**（他们） |
| 第三人称阴 | **sie**（她） | |
| 第三人称中 | **es**（它） | |

> **注意：** 尊称 **Sie** 永远大写！第三人称阴性 sie 和她复数 sie 同形，通过动词变位区分。

---

### 语法 III：规则动词现在时变位（Konjugation der regelmäßigen Verben im Präsens）

**规则：词干 + 人称词尾**

以 **kommen**（来）、**heißen**（名叫）、**lernen**（学习）为例：

| 人称        | 词尾      | kommen     | heißen           | lernen     |
| --------- | ------- | ---------- | ---------------- | ---------- |
| ich       | **-e**  | komm**e**  | heiß**e**        | lern**e**  |
| du        | **-st** | komm**st** | heiß**t**（⚠️ß+t） | lern**st** |
| er/sie/es | **-t**  | komm**t**  | heiß**t**（⚠️ß+t） | lern**t**  |
| wir       | **-en** | komm**en** | heiß**en**       | lern**en** |
| ihr       | **-t**  | komm**t**  | heiß**t**        | lern**t**  |
| sie/Sie   | **-en** | komm**en** | heiß**en**       | lern**en** |

> **注意：**
> - 词干以 **-t, -d, -chn, -ffn** 结尾时，du/er/ihr 需加 **e**：du arbeit**e**st, er arbeit**e**t
> - 词干以 **-s, -ß, -z, -x** 结尾时，du 只需 **-t**：du heiß**t**（不是 heißst）

---

### 语法 IV：sein 的现在时变位（Konjugation von "sein" im Präsens）

**sein**（是）是德语最重要的动词，**完全不规则**：

| 人称 | 变位 |
|------|------|
| ich | **bin** |
| du | **bist** |
| er/sie/es | **ist** |
| wir | **sind** |
| ihr | **seid** |
| sie/Sie | **sind** |

---

### 语法 V：命令式 (1)（Imperativ (1)）

对 **Sie**（您/您们）的命令式：

**公式：动词不定式 + Sie + 其他成分！**

| 陈述句 | 命令式（Sie） |
|--------|---------------|
| Sie kommen. | **Kommen Sie!**（您来吧！） |
| Sie lesen. | **Lesen Sie!**（您读吧！） |
| Sie gehen. | **Gehen Sie!**（您走吧！） |

> 礼貌命令只需把动词**提前到第一位** + Sie，句末用感叹号。

---

### 语法 VI：句子类型与语序（Satzarten und Wortstellung）

#### 1. 陈述句（Aussagesatz）— 动词在**第二位**

| 第一位 | 第二位（动词）| 第三位... |
|--------|---------------|-----------|
| Ich | **heiße** | Moritz Fischer. |
| Er | **kommt** | aus Deutschland. |
| Morgen | **gehe** | ich ins Kino. |

#### 2. 带疑问词的疑问句（W-Frage）— 动词在**第二位**

| 第一位（疑问词）| 第二位（动词）| 第三位... |
|-----------------|---------------|-----------|
| Wie | **heißen** | Sie? |
| Woher | **kommen** | Sie? |
| Was | **ist** | das? |

#### 3. 不带疑问词的疑问句（Ja/Nein-Frage）— 动词在**第一位**

| 第一位（动词）| 第二位... |
|---------------|-----------|
| **Kommen** | Sie aus Deutschland? |
| **Ist** | er Lehrer? |
| **Heißt** | du Eva? |

#### 4. 命令句（Imperativsatz）— 动词在**第一位**

| 第一位（动词）| 第二位... |
|---------------|-----------|
| **Lesen** | Sie! |
| **Kommen** | Sie bitte! |

## Einheit 3 — 大学生活（Studentenleben）

### 语法 I：不规则动词现在时变位（Konjugation der unregelmäßigen Verben im Präsens）

不规则动词在 **du** 和 **er/sie/es** 人称发生变音：

#### a → ä 型

| 人称 | fahren（乘车）| schlafen（睡觉）| laufen（跑）|
|------|--------------|-----------------|-------------|
| ich | fahre | schlafe | laufe |
| du | **fährst** | **schläfst** | **läufst** |
| er/sie/es | **fährt** | **schläft** | **läuft** |
| wir | fahren | schlafen | laufen |
| ihr | fahrt | schlaft | lauft |
| sie/Sie | fahren | schlafen | laufen |

#### e → i 型

| 人称 | sprechen（说话）| essen（吃）| geben（给）|
|------|-----------------|------------|------------|
| ich | spreche | esse | gebe |
| du | **sprichst** | **isst** | **gibst** |
| er/sie/es | **spricht** | **isst** | **gibt** |
| wir | sprechen | essen | geben |
| ihr | sprecht | esst | gebt |
| sie/Sie | sprechen | essen | geben |

#### e → ie 型

| 人称 | sehen（看）| lesen（读）|
|------|------------|------------|
| ich | sehe | lese |
| du | **siehst** | **liest** |
| er/sie/es | **sieht** | **liest** |
| wir | sehen | lesen |
| ihr | seht | lest |
| sie/Sie | sehen | lesen |

> **规律总结：**
> - 只有 **du** 和 **er/sie/es** 变音
> - a → ä, e → i/ie
> - 第一/三人称复数不变音

---

### 语法 II：冠词与名词的第四格（Artikel und Substantiv im Akkusativ）

**Akkusativ = 直接宾语**（"谁/什么"）

| 性 | Nominativ | Akkusativ | 例 |
|----|-----------|-----------|-----|
| 阳性 m. | der / ein | **den / einen** | Ich sehe den/einen Mann. |
| 阴性 f. | die / eine | **die / eine** | Ich sehe die/eine Frau. |
| 中性 n. | das / ein | **das / ein** | Ich sehe das/ein Kind. |
| 复数 Pl. | die / — | **die / —** | Ich sehe die/Kinder. |

> **⚠️ 关键：只有阳性变化！** der → den, ein → einen
> 阴性、中性、复数保持不变！

---

### 语法 III：人称代词第四格（Personalpronomen im Akkusativ）

| 人称 | Nominativ | Akkusativ |
|------|-----------|-----------|
| ich | ich | **mich** |
| du | du | **dich** |
| er | er | **ihn** |
| sie | sie | **sie** |
| es | es | **es** |
| wir | wir | **uns** |
| ihr | ihr | **euch** |
| sie | sie | **sie** |
| Sie | Sie | **Sie** |

例：
- Ich liebe **dich**.（我爱你。）
- Er sieht **mich**.（他看见我。）
- Sie besucht **ihn**.（她拜访他。）

| 1 | eins | 12 | zwölf |

## Einheit 4 — 家庭（Familie）

### 语法 I：可分动词（Trennbare Verben）

某些动词有**可分前缀**，在现在时中前缀**与动词分离，置于句末**。

常见可分前缀：**an-, auf-, aus-, ein-, mit-, vor-, zu-, ab-, fern-, statt-** 等

| 不定式 | 陈述句 |
|--------|--------|
| **an**rufen（打电话） | Ich rufe dich **an**. |
| **auf**stehen（起床） | Er steht um 7 Uhr **auf**. |
| **ein**kaufen（购物） | Sie kauft im Supermarkt **ein**. |
| **mit**kommen（一起去） | Kommst du **mit**? |
| **fern**sehen（看电视） | Wir sehen am Abend **fern**. |
| **zu**machen（关闭） | Mach die Tür **zu**! |

> **规则：** 在陈述句和疑问句中，动词词干按正常位置（第二位/第一位），前缀放在**句末**。

---

### 语法 II：零冠词（Nullartikel）

以下情况**不使用**冠词：

1. **职业、身份**：Ich bin **Student**. / Sie ist **Lehrerin**.
2. **国籍**：Ich bin **Chinese**.
3. **复数不定指**：Ich habe **Kinder**.（= 我有孩子，复数泛指时不加冠词）
4. **称呼**：**Herr** Müller, **Frau** Lehmann
5. **大多数国名**（中性）：**China**, **Deutschland**, **Österreich**

---

### 语法 III：否定词 kein 和 nicht

#### kein（否定名词）— 放在名词前

kein 的变格同不定冠词 **ein**：

| 性 | Nominativ | Akkusativ |
|----|-----------|-----------|
| 阳 | kein | keinen |
| 阴 | keine | keine |
| 中 | kein | kein |
| 复 | keine | keine |

例：
- Ich habe **kein** Geld.（我没有钱。）
- Er hat **keinen** Bruder.（他没有兄弟。）

#### nicht（否定动词/形容词/副词/整句）— 放在被否定成分之前

| 否定对象 | 位置 | 例 |
|----------|------|-----|
| 整句/动词 | **句末** | Ich komme **nicht**. |
| 形容词 | 形容词前 | Das ist **nicht** gut. |
| 副词 | 副词前 | Er kommt **nicht** heute. |
| 介词短语 | 介词前 | Ich gehe **nicht** ins Kino. |

> **kein vs nicht：** kein 只否定带**不定冠词/零冠词**的名词；nicht 否定其他一切。

---

### 语法 IV：物主代词第一格和第四格（Possessivpronomen im Nominativ und Akkusativ）

| 人称 | 词根 | N. 阳 | N. 阴/复 | N. 中 | A. 阳 | A. 阴/复 | A. 中 |
|------|------|-------|----------|------|-------|----------|------|
| ich | **mein-** | mein | meine | mein | meinen | meine | mein |
| du | **dein-** | dein | deine | dein | deinen | deine | dein |
| er/es | **sein-** | sein | seine | sein | seinen | seine | sein |
| sie | **ihr-** | ihr | ihre | ihr | ihren | ihre | ihr |
| wir | **unser-** | unser | unsere | unser | unseren | unsere | unser |
| ihr | **euer-** | euer | eure | euer | euren | eure | euer |
| sie | **ihr-** | ihr | ihre | ihr | ihren | ihre | ihr |
| Sie | **Ihr-** | Ihr | Ihre | Ihr | Ihren | Ihre | Ihr |

> **物主代词变格 = ein 的变格模式**（阳四 → -en，阴/复不变，中不变）

例：
- Das ist **mein** Vater.（N. 阳）
- Ich liebe **meine** Mutter.（A. 阴）
- Er besucht **seinen** Freund.（A. 阳）

---

### 语法 V：ja, nein, doch

| 问句形式 | 肯定回答 | 否定回答 |
|----------|----------|----------|
| 肯定问句 | **Ja**. | **Nein**. |
| 否定问句 | **Doch!**（不对，是的！）| **Nein**. |

> **⚠️ doch 是德语特有难点：** 当对方用否定方式提问，你要肯定回答时，用 **doch** 而非 ja！
>
> — Kommst du **nicht**?（你不来吗？）
> — **Doch!**（不，我来的！） ← 纠正对方的否定预设

| 人称 | 变位 |
|------|------|
| ich | **mag** |
| du | **magst** |
| er/sie/es | **mag** |
| wir | **mögen** |
| ihr | **mögt** |
| sie/Sie | **mögen** |

例：Ich **mag** Kaffee.（我喜欢咖啡。）

#### möchte（想要 — mögen 的第二虚拟式，更礼貌）

| 人称 | 变位 |
|------|------|
| ich | **möchte** |
| du | **möchtest** |
| er/sie/es | **möchte** |

| ihr | **möchtet** |

例：Ich **möchte** ein Bier.（我想要一杯啤酒。）

> **möchte 比 mögen 更常用**于点餐/表达愿望，更礼貌。

---

### 语法 II：第三格（Dativ）

**Dativ = 间接宾语**（"给谁/为谁"）

#### 冠词第三格

| 性 | Nominativ | Dativ |
|----|-----------|-------|
| 阳性 m. | der / ein | **dem / einem** |
| 阴性 f. | die / eine | **der / einer** |
| 中性 n. | das / ein | **dem / einem** |
| 复数 Pl. | die / — | **den / —** + **名词+n**（多数名词加 -n） |

> **口诀：** 阳中 dem，阴 der，复 den（+n）

#### 人称代词第三格

| N. | D. |
|----|-----|
| ich | **mir** |
| du | **dir** |
| er/es | **ihm** |
| sie | **ihr** |
| wir | **uns** |
| ihr | **euch** |
| sie | **ihnen** |
| Sie | **Ihnen** |

例：
- Ich gebe **dem** Mann **das** Buch.（我给那个男人那本书。）
- Wie geht es **Ihnen**?（您好吗？— 直译：您怎么样了？）

---

### 语法 III：第三格和第四格的语序（Wortstellung von Dativ und Akkusativ）

#### 两个都是名词时：Dativ 在 Akkusativ 之前

> Ich gebe **dem Mann** **das Buch**.（D+A）

#### 一个是代词一个是名词时：代词在前

> Ich gebe **ihm** das Buch.（代词 D + 名词 A）
> Ich gebe **es** dem Mann.（代词 A + 名词 D）

#### 两个都是代词时：Akkusativ 在 Dativ 之前

> Ich gebe **es** **ihm**.（A+D）

---

### 语法 IV：du 和 ihr 的命令式（Imperativ mit "du" und "ihr"）

#### du 的命令式

**公式：词干 + (e) + 其他成分！**（去掉 du 和词尾 -st，人称代词省略）

| 不定式 | 陈述 (du) | 命令式 (du) |
|--------|-----------|-------------|
| kommen | du kommst | **Komm!** |
| gehen | du gehst | **Geh!** |
| arbeiten | du arbeitest | **Arbeite!**（加 e 便于发音）|
| anrufen | du rufst an | **Ruf** ... **an!** |
| geben | du gibst | **Gib!**（保留变音）|
| essen | du isst | **Iss!**（保留变音）|

#### ihr 的命令式

**公式：词干 + t + 其他成分！**（同陈述句 ihr 形式，省略人称代词）

| 不定式 | 命令式 (ihr) |
|--------|-------------|
| kommen | **Kommt!** |
| gehen | **Geht!** |
| anrufen | **Ruft** ... **an!** |

> **Sie 的命令式**（复习）：**动词原形 + Sie!** → Kommen Sie! / Lesen Sie!

## Einheit 6 — 住在德国（Wohnen in Deutschland）

### 语法 I：情态动词 dürfen, müssen, sollen

#### 情态动词变位总规律

> **单数人称（ich, du, er）变音；复数人称（wir, ihr, sie）用原形词干**

| | dürfen（可以/允许）| müssen（必须）| sollen（应该）|
|------|-----|-----|-----|
| ich | **darf** | **muss** | **soll** |
| du | **darfst** | **musst** | **sollst** |
| er/sie/es | **darf** | **muss** | **soll** |
| wir | dürfen | müssen | sollen |
| ihr | dürft | müsst | sollt |
| sie/Sie | dürfen | müssen | sollen |

#### 情态动词的框形结构

> **情态动词在第二位（变位） + 实义动词原形在句末**

| 结构 | 例 |
|------|-----|
| 陈述句 | Ich **muss** heute arbeiten **gehen**. |
| Ja/Nein 疑问句 | **Darf** ich hier rauchen? |
| 带情态动词的句子 | Er **soll** mehr Wasser trinken. |

#### 用法区别

| 情态动词 | 含义 | 例 |
|----------|------|-----|
| **dürfen** | 允许、可以 | Hier **darf** man nicht rauchen.（此处不准吸烟。）|
| **müssen** | 必须（客观必要）| Ich **muss** zur Arbeit.（我必须上班。）|
| **sollen** | 应该（他人要求/义务）| Du **sollst** zum Arzt gehen.（你应该去看医生。）|

---

### 语法 II：支配第三格和第四格的介词（Präpositionen mit dem Dativ und mit dem Akkusativ）

#### 静三动四规则（Wechselpräpositionen）

**9 个可支配 Dativ 或 Akkusativ 的介词：**

> **an, auf, hinter, in, neben, über, unter, vor, zwischen**

**规则：**
- **静态/位置**（Wo? 在哪里？）→ **Dativ**
- **动态/方向**（Wohin? 去哪里？）→ **Akkusativ**

| 介词 | Wo?（+ D.）| Wohin?（+ A.）|
|------|-----------|---------------|
| **in** | Ich bin **in dem** Kino. → **im** Kino | Ich gehe **in das** Kino. → **ins** Kino |
| **an** | am Tisch（在桌旁）| an den Tisch（到桌旁去）|
| **auf** | auf dem Tisch（在桌上）| auf den Tisch（放到桌上）|
| **vor** | vor dem Haus（在房前）| vor das Haus（到房前去）|
| **hinter** | hinter dem Haus（在房后）| hinter das Haus（到房后去）|
| **neben** | neben dem Tisch（在桌旁）| neben den Tisch（到桌旁去）|
| **über** | über dem Tisch（在桌上方）| über den Tisch（到桌上方）|
| **unter** | unter dem Tisch（在桌下）| unter den Tisch（到桌下）|
| **zwischen** | zwischen den Häusern | zwischen die Häuser |

#### 介词与冠词的缩合

| 介词 + 冠词 | 缩合 | 例 |
|-------------|------|-----|
| in + dem | **im** | im Kino, im Haus |
| in + das | **ins** | ins Kino |
| an + dem | **am** | am Tisch, am Morgen |
| an + das | **ans** | ans Meer |
| auf + das | **aufs** | aufs Land |
| zu + dem | **zum** | zum Arzt |
| zu + der | **zur** | zur Schule |
| bei + dem | **beim** | beim Essen |

## Einheit 7 — 购物与送礼（Kaufen und Schenken）

## Einheit 8 — 休闲与度假（Freizeit und Ferien）

### 语法 I：现在完成时（Perfekt）

**现在完成时 = 德语口语中最常用的过去时态！**

> **公式：haben/sein (现在时变位) + Partizip II（句末）**

#### Partizip II（第二分词）构成

**规则动词：ge + 词干 + (e)t**

| 不定式 | P.II |
|--------|------|
| machen | **ge**mach**t** |
| lernen | **ge**lern**t** |
| arbeiten | **ge**arbeit**et**（词干 -t 结尾加 -et）|
| warten | **ge**wart**et** |

**规则动词不加 ge- 的情况：**
- 以 **-ieren** 结尾：studieren → studier**t**（⚠️ 无 ge-）
- 非重读前缀：besuchen → **be**such**t**（⚠️ 无 ge-）
- 可分动词：**an**rufen → **an**ge**rufen**（⚠️ ge 在前缀和词干之间）

**不规则动词（强变化）：ge + 变化词干 + en**

| 不定式 | P.II | 不定式 | P.II |
|--------|------|--------|------|
| kommen | ge**kommen** | sehen | ge**sehen** |
| gehen | ge**gangen** | lesen | ge**lesen** |
| essen | ge**gessen** | schreiben | ge**schrieben** |
| trinken | ge**trunken** | finden | ge**funden** |
| sprechen | ge**sprochen** | nehmen | ge**nommen** |
| bleiben | ge**blieben** | fahren | ge**fahren** |

> **⚠️ 不规则动词的 P.II 必须逐词记忆！** 常见模式：词干元音变化（ie→o, e→a, i→u 等）

#### haben 还是 sein？

| 用 haben | 用 sein |
|-----------|--------|
| 绝大多数动词 | **位移动词**（有方向变化）|
| 及物动词（+Akk.）| fahren, gehen, kommen, laufen, fliegen... |
| 反身动词 | **状态变化动词** |
| 无人称动词 | aufstehen, einschlafen, sterben, werden... |
| | **sein, bleiben, passieren** |

例：
- Ich **habe** ein Buch **gelesen**.（haben + lesen）
- Ich **bin** nach Berlin **gefahren**.（sein + 位移 fahren）
- Er **ist** um 7 Uhr **aufgestanden**.（sein + 状态变化）

---

### 语法 II：sein 和 haben 的过去时（Präteritum）

> **sein 和 haben 在口语中也常用 Präteritum 替代 Perfekt！**

| 人称 | sein | haben |
|------|------|-------|
| ich | **war** | **hatte** |
| du | **warst** | **hattest** |
| er/sie/es | **war** | **hatte** |
| wir | **waren** | **hatten** |
| ihr | **wart** | **hattet** |
| sie/Sie | **waren** | **hatten** |

例：
- Gestern **war** ich im Kino.（昨天我在电影院。）
- Früher **hatte** ich viel Zeit.（以前我有很多时间。）

---

### 语法 III：第二格作为定语（Genitiv als Attribut）

**Genitiv = 所属关系**（"谁的"）

| 性 | 定冠词 | 不定冠词 | 例 |
|----|--------|----------|-----|
| 阳 | **des** + 名词+(e)s | **eines** + 名词+(e)s | das Buch des Mann**es** |
| 阴 | **der** | **einer** | das Buch der Frau |
| 中 | **des** + 名词+(e)s | **eines** + 名词+(e)s | das Buch des Kind**es** |
| 复 | **der** | — | das Buch der Kinder |

> **阳性/中性名词在 Genitiv 中通常加 -s 或 -es**（单音节名词加 -es）

例：
- Das ist das Auto **meines Vaters**.（那是我父亲的车。）
- Die Farbe **des Hauses** ist schön.（房子的颜色很漂亮。）

## Einheit 9 — 身体与健康（Körper und Gesundheit）

### 语法 I：反身代词和反身动词（Reflexivpronomen und reflexive Verben）

#### 反身代词（= 第四格人称代词，除了 er/sie/es → sich）

| 人称 | 反身代词（A.）| 反身代词（D.）|
|------|---------------|---------------|
| ich | **mich** | **mir** |
| du | **dich** | **dir** |
| er/sie/es | **sich** | **sich** |
| wir | **uns** | **uns** |
| ihr | **euch** | **euch** |
| sie/Sie | **sich** | **sich** |

> **⚠️ 第三人称（er/sie/es）和尊称（Sie）的反身代词都是 sich！**

#### 常见反身动词

| 带 A. 的反身动词 | 含义 |
|-------------------|------|
| sich freuen | 高兴 |
| sich interessieren (für) | 感兴趣 |
| sich setzen | 坐下 |
| sich anziehen | 穿衣 |
| sich waschen | 洗脸/洗澡 |
| sich fühlen | 感觉 |
| sich erkälten | 感冒 |
| sich treffen | 见面 |

| 带 D. 的反身动词 | 含义 |
|-------------------|------|
| sich (D.) etw. ansehen | 观看 |
| sich (D.) etw. wünschen | 希望得到 |
| sich (D.) etw. vorstellen | 想象 |

> **区分：** 大多数反身动词带 Akkusativ；如果已有 A. 宾语，反身代词用 Dativ。

例：
- Ich **freue mich**.（我很高兴。）
- Ich **wasche mich**.（我洗脸。）
- Ich **sehe mir** den Film **an**.（我看这部电影 — D. 因为 Film 是 A. 宾语）

---

### 语法 II：宾语从句（Objektsatz mit "dass", "ob" und Fragewörtern）

#### 1. dass 引导的宾语从句（dass = "……这件事"）

> 主句 + **dass** + 从句（变位动词在**从句末**）

例：
- Ich weiß, **dass** er krank **ist**.（我知道他生病了。）
- Ich hoffe, **dass** du kommen **kannst**.（我希望你能来。）

#### 2. ob 引导的宾语从句（ob = "是否"）

> 用于间接疑问，无疑问词时用 ob

例：
- Ich weiß nicht, **ob** er kommt.（我不知道他是否来。）
- Frag ihn, **ob** er Zeit hat.（问他有没有时间。）

#### 3. 疑问词引导的宾语从句（W-Fragewörter）

> 间接疑问句中，疑问词不变，但变位动词放从句末

例：
- Weißt du, **wann** der Zug **kommt**?（你知道火车什么时候来吗？）
- Sag mir, **wo** du **wohnst**.（告诉我你住哪里。）
- Ich frage, **warum** er nicht **gekommen ist**.（我问为什么他没来。）

#### 从句语序总结

| 直接问句（独立句）| 间接问句（从句）| 说明 |
|-------------------|-----------------|------|
| Wann **kommt** er? | ..., wann er **kommt**. | 疑问词保留，动词→从句末 |
| **Kommt** er? | ..., **ob** er **kommt**. | 无疑问词→加 ob |
| — | ..., **dass** er **kommt**. | 陈述→ dass 从句 |

> **核心规则：从句中变位动词永远在最后！**

## Einheit 10 — 城市导向（Orientierung in der Stadt）

### 语法 I：介词 über, durch, um, entlang, gegenüber

#### 始终支配 Akkusativ 的介词

| 介词 | 含义 | 例 |
|------|------|-----|
| **durch** | 穿过、通过 | Wir gehen **durch** den Park. |
| **um** | 围绕、在…周围；在…点 | Er läuft **um** das Haus. / **Um** 8 Uhr. |
| **entlang** | 沿着（**后置**）| Gehen Sie die Straße **entlang**. |
| **gegen** | 反对；大约（时间）| Er ist **gegen** den Plan. / **Gegen** 10 Uhr. |
| **für** | 为了、支持 | Das Geschenk ist **für** dich. |
| **ohne** | 没有 | Ohne dich gehe ich nicht. |

#### 始终支配 Dativ 的介词

| 介词 | 含义 | 例 |
|------|------|-----|
| **mit** | 和……一起；用 | Ich fahre **mit** dem Bus. |
| **nach** | 向……（方向）；在……之后 | Ich fahre **nach** Berlin. / **Nach** dem Essen. |
| **bei** | 在……附近；在……时 | Er wohnt **bei** Berlin. / **Beim** Essen. |
| **seit** | 自从（时间）| **Seit** einem Jahr lerne ich Deutsch. |
| **von** | 从……来；……的 | Ich komme **von** der Arbeit. |
| **zu** | 去……；到…… | Ich gehe **zum** Arzt. |
| **aus** | 从……出来（空间）| Ich komme **aus** China. |
| **gegenüber** | 在……对面（**可前置/后置**）| **Gegenüber** der Post / Der Post **gegenüber** |

#### für 和 um 的特别用法

- **für** + A. = 为了：Das ist **für** dich.
- **um** + A. = 在……点钟：**um** 8 Uhr
- **um** + A. = 围着：**um** den Tisch

### 语法 II：情态动词总复习（Wiederholung der Modalverben）

#### 六个情态动词变位汇总

| | **können** | **dürfen** | **müssen** | **sollen** | **wollen** | **mögen/möchte** |
|------|------|------|------|------|------|------|
| ich | kann | darf | muss | soll | will | mag / möchte |
| du | kannst | darfst | musst | sollst | willst | magst / möchtest |
| er/es/sie | kann | darf | muss | soll | will | mag / möchte |
| wir | können | dürfen | müssen | sollen | wollen | mögen / möchten |
| ihr | könnt | dürft | müsst | sollt | wollt | mögt / möchtet |
| sie/Sie | können | dürfen | müssen | sollen | wollen | mögen / möchten |

#### 六大情态动词含义总结

| 情态动词 | 核心含义 | 例句 |
|----------|----------|------|
| **können** | 能够、会、可能 | Ich kann schwimmen. |
| **dürfen** | 允许、可以 | Darf ich rein? |
| **müssen** | 必须（客观）| Ich muss lernen. |
| **sollen** | 应该（他人要求）| Du sollst kommen. |
| **wollen** | 想要（强烈意志）| Ich will gehen. |
| **möchte** | 想要（礼貌愿望）| Ich möchte ein Bier. |

#### 情态动词宾语人称

> 情态动词要求用 **Nominativ 主语**，而非 "es gibt" 等句式

例：Ich **möchte** einen Kaffee.（≠ Mir möchte einen Kaffee. ⚠️）
