### ️ 光标移动与文本编辑
| 快捷键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **Ctrl + A** | 光标瞬间跳到**行首** | A = Ahead  |
| **Ctrl + E** | 光标瞬间跳到**行尾** | E = End  |
| **Ctrl + F** | 光标向右移动一个字符 | F = Forward  |
| **Ctrl + B** | 光标向左移动一个字符 | B = Backward  |
| **Alt + F** | 光标向右跳一个**单词** | F = Forward |
| **Alt + B** | 光标向左跳一个**单词** | B = Backward |
| **Ctrl + T** | 交换光标前两个字符的位置 | 快速修正手滑打错的字母 |
| **Alt + T** | 交换光标前两个单词的位置 | 快速调整单词顺序 |
| **Ctrl + L** | 清空终端屏幕（等同于 clear） | L = Layout (重新布局) |

### ️ 快速删除与剪切粘贴
| 快捷键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **Ctrl + U** | 删除（剪切）从光标处到**行首**的所有内容 | U = Undo (撤销整行) |
| **Ctrl + K** | 删除（剪切）从光标处到**行尾**的所有内容 | K = Kill (杀掉后面) |
| **Ctrl + W** | 删除（剪切）光标前的**一个单词** | W = Word (单词) |
| **Alt + D** | 删除光标后的**一个单词** | D = Delete |
| **Ctrl + H** | 删除光标前的一个字符（等同于退格键） | H = Hit (敲击删除) |
| **Ctrl + D** | 删除光标处的一个字符 | 也是退出当前 Shell 的快捷键 |
| **Ctrl + Y** | 粘贴（恢复）最近一次被删除的内容 | Y = Yank (拉回/粘贴) |

###  历史命令与进程控制
| 快捷键 | 功能说明 | 场景 |
| :--- | :--- | :--- |
| **Ctrl + R** | 反向搜索历史命令 | 输入关键词，自动匹配之前输过的长命令 |
| **Ctrl + P** | 上一条历史命令 | P = Previous (等同于按↑键) |
| **Ctrl + N** | 下一条历史命令 | N = Next (等同于按↓键) |
| **Ctrl + C** | 强制终止当前正在运行的程序 | 程序卡死或不想等了，直接按它 |
| **Ctrl + Z** | 将当前程序挂起到后台暂停 | 配合 `fg` (恢复前台) 或 `bg` (后台运行) 使用 |
| **Ctrl + S** | 暂停终端的所有输出 | 防止日志刷屏太快看不清 |
| **Ctrl + Q** | 恢复被 Ctrl+S 暂停的终端输出 | 解除屏幕冻结状态 |
| **!!** | 快速执行上一条命令 | 常用于 `sudo !!` (给上一条命令加sudo权限) |
| **Alt + .** | 粘贴上一条命令的最后一个参数 | 比如刚输完 `cd /a/b/c`，按它能直接打出路径 |
