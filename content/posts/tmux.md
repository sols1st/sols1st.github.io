###  核心概念
tmux 采用三层结构来管理工作环境：
*   **会话 (Session)**：独立的工作空间，可在后台运行。
*   **窗口 (Window)**：会话中的单个视图，类似浏览器的标签页类。
*   **窗格 (Pane)**：窗口的分割区域，可同时显示多个终端。

---

### ️ 基础操作与快捷键
tmux 的所有快捷键都需要先按下**前缀键（Prefix）**，默认是 `Ctrl + b`。按下后松开，再按后续的功能键。

#### 1. 会话管理 (Session)
会话是 tmux 的核心，掌握以下命令即可保证任务不中断。

| 操作 | 快捷键 (Prefix 后) | 命令行指令 |
| :--- | :--- | :--- |
| **新建会话** | - | `tmux new -s <会话名>` |
| **分离会话** (后台运行) | `d` | `tmux detach` |
| **列出所有会话** | `s` | `tmux ls` |
| **接入/恢复会话** | - | `tmux attach -t <会话名>` |
| **重命名会话** | `$` | `tmux rename-session -t <旧名> <新名>` |
| **杀死指定会话** | - | `tmux kill-session -t <会话名>` |
| **杀死所有会话** | - | `tmux kill-server` |

 **懒人技巧**：使用 `tmux new -A -s <会话名>`，如果会话存在就直接接入，不存在则新建。

#### 2. 窗口管理 (Window)
类似浏览器的标签页操作，用于在同一任务下区分不同工作。

| 操作 | 快捷键 (Prefix 后) |
| :--- | :--- |
| **新建窗口** | `c` |
| **关闭当前窗口** | `&` |
| **下一个窗口** | `n` |
| **上一个窗口** | `p` |
| **按编号切换** | `0` 到 `9` |
| **重命名窗口** | `,` |
| **窗口列表选择** | `w` |

#### 3. 窗格管理 (Pane)
高效利用屏幕空间，实现多任务并行。

| 操作 | 快捷键 (Prefix 后) |
| :--- | :--- |
| **水平分割** (上下布局) | `"` |
| **垂直分割** (左右布局) | `%` |
| **切换窗格** | `方向键` 或 `o` |
| **关闭当前窗格** | `x` |
| **全屏/恢复窗格** | `z` |
| **显示窗格编号** | `q` |
| **调整窗格大小** | `Ctrl + 方向键` |
| **循环切换布局** | `空格键` |

#### 4. 复制与滚动模式 (Copy Mode)
在 tmux 中查看长日志或历史输出时，默认的终端滚动可能不够用，需要进入复制模式。

| 操作 | 快捷键 (Prefix 后) | 说明 |
| :--- | :--- | :--- |
| **进入复制模式** | `[` | 可用方向键或 PgUp/PgDn 滚动 |
| **退出复制模式** | `q` | 退出浏览 |
| **开始选择文本** | `空格键` | 在复制模式下按空格开始 |
| **复制选中文本** | `回车键` | 复制后自动退出模式 |
| **粘贴文本** | `]` | 粘贴刚才复制的内容 |

### ️ 进阶配置与实用技巧

#### 个性化配置
可以通过创建或编辑 `~/.tmux.conf` 文件来优化 tmux 体验。修改后，在 tmux 中按下 `Prefix + :` 输入 `source-file ~/.tmux.conf` 即可重载配置。

```bash
# 将前缀键改为 Ctrl+a（很多用户觉得更顺手）
set -g prefix C-a
unbind C-b
bind C-a send-prefix

# 开启鼠标支持（可用鼠标点击切换窗格、调整大小）
set -g mouse on

# 设置更短的命令延迟
set -sg escape-time 0
```

#### 同步操作窗格
如果要在同一个窗口的多个窗格中输入相同的命令（例如同时操作多台服务器），可以开启同步模式：
*   开启：`Prefix + :` 输入 `setw synchronize-panes on`
*   关闭：`Prefix + :` 输入 `setw synchronize-panes off`

#### 常用别名 (Alias)
为了进一步提升效率，可在 `.bashrc` 或 `.zshrc` 中设置别名：
```bash
alias t='tmux new -A -s'  # 用法：t myproject (一键新建或接入)
alias tl='tmux ls'        # 列出会话
alias tk='tmux kill-server' # 关闭所有会话
```
